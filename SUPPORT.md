# Support

## Asking a question

- **Bugs and feature requests:** open a GitHub issue using the matching
  template under `.github/ISSUE_TEMPLATE/`.
- **Security:** do **not** open a public issue. See `SECURITY.md`.
- **General questions about AIOS architecture or contracts:** open a
  GitHub discussion (once the repository is published) or read the docs
  in `docs/`.

## What is in scope

- Bug reports that include a minimal reproduction.
- Documentation fixes and clarifications.
- New Provider / Tool / Workflow examples (Demo / stub only).
- Test infrastructure improvements.
- Hardening improvements for the offline / CI paths.

## What is out of scope

- Feature requests for paid Providers that require us to spend real
  budget to validate. Please propose a stub adapter or a contract change
  instead.
- Issues caused by third-party libraries — please report those upstream.
- Running AIOS for you. This is an Alpha project; operators run it
  themselves.

## Response time expectations

AIOS is Alpha. Maintainers respond to issues on a best-effort basis. We
do not promise SLAs.

## Code of Conduct

All community spaces follow `CODE_OF_CONDUCT.md`.
